# Experiment 2 – Active and Passive Reconnaissance

## Aim
To perform active and passive reconnaissance using Wireshark and Nmap in an authorized lab environment.

## Tools Used
- Wireshark
- Nmap

## Procedure
1. Open Wireshark and select the appropriate network interface.
2. Start capturing network traffic in the authorized lab environment.
3. Observe the captured packets and identify relevant network information.
4. Open Nmap and scan the authorized lab target or local test machine.
5. Observe the scan output, including discovered hosts and available ports.
6. Save screenshots of the actual results.
